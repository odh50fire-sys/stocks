# 📱 24H 글로벌 주식 모바일 앱 & 6x6 위젯

주말 및 야간 거래 주요 지표 12종을 **상하/좌우 무스크롤(No-Scroll)** 단일 모바일 화면에 제공하고, 상세 캔들 차트 및 **6x6 홈스크린 위젯**을 지원하는 모바일 전용 앱입니다.

## 🚀 실행 방법

```bash
# 1. 서버 실행 (백엔드 데이터 수집기 및 정적 웹앱 호스팅)
python server.py

# 2. 브라우저에서 접속
http://localhost:8080
```

## ✨ 핵심 기능

1. **상하/좌우 무스크롤 100dvh 모바일 레이아웃**
   - 모바일 뷰포트 내 2열 6행(총 12개 셀)이 오차 없이 정확히 분할되어 한눈에 조망 가능
   - 가격 변동 시 부드러운 네온 플래시 효과 (상승: 레드, 하락: 블루)
2. **전문 TradingView Lightweight 캔들 차트**
   - 원천 API 규명 종목(8종): 5분 / 15분 / 1시간 / 1일 OHLCV 캔들스틱 + 거래량(Volume) + 이동평균선(MA5, MA20) + 십자선 크로스헤어
   - 크롤링 전용 종목(4종): 실시간 호가 및 통계 요약 카드 표기
3. **6x6 크기 홈스크린 위젯 모드**
   - 우측 상단 `[ 📱 6x6 위젯 ]` 버튼을 누르면 스마트폰 6x6 위젯 뷰 렌더링
   - 위젯 종목 탭 시 해당 종목의 상세 화면으로 즉시 딥링크 연결
4. **PWA(Progressive Web App) 지원**
   - 스마트폰 브라우저에서 '홈 화면에 추가' 시 네이티브 앱처럼 전체화면 구동
